# Basic operations of Git and GitHub

## 1.  Pulling and pushing code on GitHub

### 1.1 Three concepts

| Concepts | Meanings                                                     |
| -------- | ------------------------------------------------------------ |
| Git      | Git is a version control tool installed locally on your computer that records changes to your code. |
| GitHub   | A website that hosts code repositories in the cloud.         |
| remote   | A channel that connects the local environment to GitHub.     |
