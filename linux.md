#  Linux Operating System

## 1. basic Linux

### 1.1 Linux directory structure

- **The directory structure of Linux is a tree-like structure.**
- **Linux does not have the concept of drive letters; It has only one root directory,"/",under which all files are organized.**

#### 1.1.1 Linux path notation

- **In Linux systems, the hierarchical relationship between paths is indicated by using: /**

  ```
  e.g. /usr/local/hello.txt
  ```

- **In Windows systems, the hierarchical relationship between paths is indicated by using: \\**

  ```
  e.g. D:\data\work\hello.txt
  ```

### 1.2 Linux commands for beginners

#### 1.2.1 What are commands and the command line?

- **Command line: Also known as the Linux terminal, it is a command-prompt interface. It operates the system using plain "characters" and allows you to issue operational instructions through various character-based commands.**
- **Command: A Linux program. Each command is a Linux program. Commands do not have graphical interfaces and provide character-based feedback in command line(terminal).**
